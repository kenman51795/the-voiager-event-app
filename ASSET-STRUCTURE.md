# Card asset structure

Each expansion uses the same folder layout:

```text
assets/
  deck-name/
    main/
      card1.png
      card2.png
      ...
    final/
      final.png
```

Configured expansion folder names:

- `the-voiager`
- `curious-hearts`
- `departure`
- `eternal-flame`
- `family-legacy`
- `family-ties`
- `inner-circle`
- `walk-of-faith`

Solitaire has been retired and is not included.
